机器可读全文在 `rules/journal-rules.yaml`。这里只写迁移结果：原规则从哪来、现在的值、改了没有。没有被主人明确改掉的冲突，行为保持原样，并记在文末。

## 主人这次明确改过的

| 规则 | 原来的出处 | 现在 | 为什么改 |
|---|---|---|---|
| 留白 | 轮廓和 Adobe 早已是 0.25pt；direct-pdf 缺省曾写成 2pt，加工证据要求 ≥1.99pt，AGENTS.md 写至少 2pt | 四边都是成品边缘到内容墨迹 0.25pt | 主人确认全部路径用 0.25pt，并去掉 2pt 门槛 |

## 主人随后定下来的

| 事项 | 决定 |
|---|---|
| 图例括号 | 保持原样，不改成斜杠 |
| fill_width | 它会把窄图摊满 80/160mm，已禁止。同组等宽仍用 equal_width / equal_width_groups，按最长一项取宽 |
| PDF 留白 | 只有规则文件里的 margin_pt，现为 0.25pt，只用于矢量 PDF。JPG 不加。不再保留 0–12pt |
| 灰度容差 | 保持通道差 2，印刷阶段再查 |
| 汇总线 | 默认引出改成 1.06mm（约 3pt），写在 summary_bus_leg_mm，可改。有箭头时仍留出箭头长度 |
| PNG | 不是交付物。内部预览可以留，不上传 |
| 60mm | 简单统计图先用 60mm，指定单栏也一样；放不下再用 80mm。旧稿手调的 80mm 不当标准 |
| 上下标 | 科学计数法上标比例 0.7，基线位移为 -0.4 倍基础字号（负号表示上移）。6pt 只约束正文 |
| 文件名和字体 | 只用 图N 或 图N.M。字体只有宋体、汉仪中宋简、Times New Roman。等线和 Adobe 宋体算错误 |
| 密点图 | 点或线超过规则阈值时，必须在 job 里写 bitmap_plot_vector_text: true 才改成位图图面加矢量文字 |
