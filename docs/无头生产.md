# 无头生产

工作台仍然可以打开，用来看进度和审校。做图不依赖它，也不读 `november-data.js`。

```bash
node journal.mjs doctor
node journal.mjs produce --input <期次或作者目录> [--output <目录>] [--job job.json]
```

不写 `--output` 时，成品放在该图所在的作者目录，文件名是 `作者-图1` 或 `作者-图1.2`。已有同名文件不会被盖掉，来源文件也不会被改写。

`job.json` 用来记下主人已经做过的决定，例如单位是不是单位、这张截图是网页还是单独一图。代理先读它。

分流：

- 网页截图、照片、CiteSpace、没有标明的位图：只转灰度，并在不超过栏宽的前提下缩小，交付 JPG。不重绘，不做文字可读性门禁。
- 任务里写明是单独一张统计图、且只有截图：要裁出图区并把文字做成矢量。没有图区记录时停下来，不编数据。
- SVG、PDF、Word 或 Excel 里的图：先收成 PDF。SVG 里的 `data:image` 会抽出来。

Illustrator 还在仓库里，用来合并成品，以及和主人自己的 Illustrator 打交道。常规出图不调用它来画。

有旧的 `november-data.js` 时，工作台仍按原文件加载。没有这份文件时，工作台改为扫描期次目录：每个作者一个文件夹，里面是 Word 和 `作者-图N.pdf` / `作者-图N.jpg`。
