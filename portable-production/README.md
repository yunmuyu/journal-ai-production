# 本地期刊图件生产入口

本目录是 **2026.10.20-r32-production-baseline** 正式交付的当前制作路线，汇合前置筛选、作者目录状态管理和直接 PDF 引擎。安装与升级见 [正式版指南](../docs/RELEASE-GUIDE.md)。能力按 `direct-pdf/docs/CAPABILITIES.json` 逐项判断；正式发布不扩大原有支持范围。

## 接手流程

1. 在仓库外复制 `config.example.json` 并填写交付目录、状态目录、字体配置和缓存目录。禁止把机器配置或字体文件提交仓库。
2. 用 `preflight/` 检查 Word、图源和可处理性；用 `localflow/` 建立来源映射、选择路线、保留候选与替换备份；由 `direct-pdf/` 的公共 scene、layout、font 和 PDF audit 生成/检查支持范围内的 PDF。
3. 根据 Word 全部图号和实际 PDF 内容完成内部检查，再把成品放回 `编辑＋篇数/0没做完/作者/作者-图号.pdf`。内部通过仍标作等待作者终审；只有作者明确终检后才记录为终审通过。

PS/JPG 图统一按单栏作为默认排版，用户明确指定双栏时再调整。不要制作 PS 查验包。相同处理动作按类集中执行，输出仍按作者归位；独立离线任务可以并行，共享 Adobe 会话和同一目标文件必须串行隔离。正式文件替换前校验当前 hash，旧稿留在状态目录的回退归档。作者原件始终保留。

## 已固化的公共约束

- 直接 PDF 流程、复用现有筛选/字体/布局/交付保护工具；不要在作者脚本另写测字、箭头或字体子集算法。
- 流程图普通连接采用公共四节点头箭头布局，基础长度 3 mm 且端点贴框；文字框以真实墨迹计算，8 pt 参考留白左右 4.5 pt、上下 2.7 pt。
- 版面先紧凑重排，允许 6–8 pt；低于 6 pt 要重新排布。输出描边可见线宽目标 0.5 pt。数学变量斜体、数字正体、上下标按语义排版。
- 常规柱图顶端数值标签测量实际墨迹并维持同一间距；发生碰撞时重排图表，不用高低错落掩盖冲突。
- 内部来源/内容/版式复核与用户终审是两个状态。未经作者终审，状态不能写作通过。

## 实测范围与限制

本地 Windows 上已有真实图件生产记录；当前验收范围见 [r32 发布说明](../release-notes/2026.10.20-r32-production-baseline.md)。[旧收尾记录](CLOSEOUT-STATUS.md) 保留为历史问题证据，不能代替当前任务状态。私有证据和作者图件保存在授权私有位置。代码可运行不代表跨机运行或 Adobe/PS 自动链路已验收。PS 自动制作、任意转曲 SVG 文字重建、复杂多面板、复杂嵌套 Form 描边归一、用户字体/Adobe 插件在新机器上仍需分别验证。

开始具体任务先看 [AGENTS.md](AGENTS.md)、当前本地任务表、[直接 PDF 使用说明](direct-pdf/README.md)与[能力表](direct-pdf/docs/CAPABILITIES.json)。历史工作台及 Illustrator/Photoshop 脚本保留为兼容路线；普通新任务不要求先走工作台同步或制作前逐图确认。

## 任务质量门禁

对子代理批量任务需要保存输入、产物和独立复核证据时，使用[质量优先任务协议](task-quality-workflow.md)和[四阶段 CLI](task_quality/README.md)。它复用现有来源哈希和交付保护，不能替代源图核对、视觉复核或用户终审。
