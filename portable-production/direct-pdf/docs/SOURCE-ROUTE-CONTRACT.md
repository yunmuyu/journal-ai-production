# 原图连线路径锁（可选）

结构合同只证明连接关系及端口，不限制折角位置。需要保留原图走线时，首次核对原图后，
将全部原始路线坐标和全图坐标映射保存为独立 JSON。后续重绘只引用该文件，不能从待检
候选反向生成合同来证明候选正确。原始箭头若以短轴线加箭头图元表示，须先人工核对实际
端点；将线轴、箭头尖和真实接框位置区分清楚，再固定完整可见路线，不能自动推断或忽略。

在制作说明的 `sources` 中，以 `role: "original-artwork"` 登记原件及 SHA-256，
以 `role: "route-contract"` 登记独立合同及其 SHA-256。制作说明设置
`"source_route_contract": "routes.json"`。如已登记合同却省略引用，检查会失败；
`policy.require_source_route_contract: true` 也可以强制要求。旧任务没有声明时报告
`source_route_audit.status: "not-checked"`，不补写历史检查通过。

下面仅是合成坐标示例；真实原件、合同和机器路径不入库。

```json
{
  "version": 1,
  "source_sha256": "<原始文件的SHA-256>",
  "transform": {"kind": "uniform", "matrix": [0.8, 0, 0, 0.8, 5, 7]},
  "routes": {
    "original-ab": {
      "points": [[10, 10], [40, 10], [40, 50], [70, 50]],
      "components": ["ab"],
      "arrow": "end",
      "arrow_style": "standard",
      "line": "solid"
    }
  }
}
```

矩阵顺序为 `[a, b, c, d, tx, ty]`，映射为
`x' = a*x + c*y + tx`、`y' = b*x + d*y + ty`，目标是制作说明的设计坐标（pt）。
`uniform` 仅允许正等比缩放和平移；确需非等比、旋转、剪切或反射时必须在独立合同中
明确使用可逆的 `affine`。所有路线共享同一个矩阵；不接受逐线变换、不自动拟合，
也不能把折角改动隐藏成每条线各自的平移。编译器的最终整图等比缩放自动合成并记录在
`effective_matrix`；导出 CropBox/留白只改变页面框，不改变本项检查的场景坐标。

`components` 是实际 Scene 路径 ID 的有序列表，全部按当前点序遍历。
共享母线可以被多条原始路线引用，例如两条路线分别登记 `["stem", "branch-a"]`
和 `["stem", "branch-b"]`。组件必须精确接续，不能跨过空隙或舍弃接点偏差；
共享母线不能带额外箭头。双向箭头和轮廓块箭头目前须以单条完整路径表示。

每条路线检查：

- 两端和全部折角在唯一全图变换下的位置、折角数量及逐段遍历方向。
- 箭头 `none/end/both`、箭头形态 `standard/block-outline`、实虚线 `solid/dashed`。
- 所有 Scene 路径都必须出现在合同中，标记 `decorative` 不能豁免多出的路径。
- 只删除同向共线的冗余采样点；真实折角和共线折返不能删除。
- 坐标沿用公共端点 0.15 pt 容差，调用方不能放宽。共线及组件接续仅使用 1e-7 pt
  数值容差，两者都不是出版间距规则。

公共 `render_one` 在输出前执行此项审计，失败不写入新 PDF 或替换已有候选。
启用后也自动使用现有最终可见性检查，重新打开保存的 PDF 核对路径、节点和文字墨迹，
防止正确场景被后续白块、裁切或覆盖破坏。该检查没有来源结构合同则仍明确记录
`source_topology_checked: false`，不会把几何证明当作原图语义证明。

边界：本合同不自动识别原图，不证明人工选取路线及原稿配对本身正确，不核验节点身份、
文字或嵌入 PDF/位图内部的连线，不锁定虚线的具体节距。需要节点/端口语义时应同时使用
[独立来源结构合同](STRUCTURE-AND-VISIBILITY.md)。自由边框可在不改已固定路线的前提下
调整容纳文字；布局器如移动了固定路径，将明确报错，不能只凭拓扑相同放行。

回归全部使用合成来源，覆盖保留端点的折角移动、删折角/新增绕行、反向、多线/漏线、
同向共线采样与折返、共享母线断点、实虚线/箭头形态、全图 uniform/affine 及最终缩放、
无效或逐线变换、哈希与原件绑定缺失，以及公共渲染报告和实际 PDF 可见性。
本地真实只读回放使用既有独立复核坐标及保存的 Scene 报告，并校验原件和 PDF 哈希；
这不等于重新交付图件、用户验收或生产版本上线。
