# 原始区域独立核验（开发版）

原有素材路径保真检查验证的是“准备文件 → 输出”，无法发现准备文件此前已漏图层。
新门禁在公共 `render_one` 中、创建输出目录之前比较“登记原始区域 → 准备素材”。
不依赖 Agent 填写 `checked: true`，不修改已安装版本或历史验收。

## 使用

来源清单将作者原件登记为 `role: "original-artwork"`，中间文件登记为 `role: "derived"`，
二者都绑定当前 SHA-256。原件登记自动启用所有 scene 素材的门禁；显式设 false 不能取消。
也可通过 `policy.require_original_asset_reference: true` 要求门禁。

每个 scene asset 增加：

```json
"original_reference": {
  "path": "original.pdf",
  "page": 0,
  "clip": [10, 20, 70, 60]
}
```

裁区用原始 PDF 页面坐标、pt 单位，不能用中间图的局部坐标替代。
登记引用即检查，即使任务未开启全量门禁也不能忽略该引用。

对于 chart，在 `original_asset_references` 中按每个实际素材 ID（例如 `plot`、`swatch:series1`）登记上述引用；必须完整覆盖。原件支持 PDF、PNG、JPG：位图使用整数像素裁区且页号为 0。原件登记必须绑定原始文件，不能把中间转换文件冒充原件；经过遮盖的素材与原区域不一致时会被拒绝。

## 实际检查

- 独立原件身份、页号、有限且有效的裁区、素材宽高比。
- 原件与准备素材使用同一实际放置后端、白底灰度渲染，最长边 600 像素。
- 灰度差大于 8/255 的像素占比不得超过 0.1%。这是抑制转换抗锯齿差异的工程容差，
  不是期刊的间距数值，也不证明任意细节逐像素完全一致；不开放调用者自行放宽。
- 不抹除白色，不忽略背景，不提供任意遮罩。漏白层、明显裁切、加框和漏线须报错。
- 报告记录原件哈希、页号、裁区、准备字节哈希、差异比例和覆盖范围。

## 边界

当前原始参照为 PDF、PNG、JPG，准备素材可为现有后端支持的矢量或位图。SVG 原件含嵌入图片、
有意去底色或换字的区域尚不能据此自动证明；不支持时应阻断或走独立的已验证专项路径。
不能把未经校验的 SVG 转换结果登记为“作者原件”来绕过边界。

本门禁证明的是已声明原始区域内的素材保真，不证明该区域选得正确、来源声明真实，
不核验重排后新画的节点/连线关系，也不单独核验最终页面其他对象覆盖素材。
这两项由[独立结构合同及最终可见性门禁](STRUCTURE-AND-VISIBILITY.md)承担，各自报告覆盖范围。
旧任务没有独立原件引用时保留兼容，但报告明确 `not-checked`，不升级为源图保真已通过。

## 回归

`tests/test_original_asset_reference.py` 通过公共渲染入口测试完整素材、栅格化素材、
漏白层、缺第二道虚线、额外边框、裁切变化、缺引用、错误来源角色及开关绕过。
错误样例必须在输出候选之前失败。全部样例为人工合成，不包含作者资料。
