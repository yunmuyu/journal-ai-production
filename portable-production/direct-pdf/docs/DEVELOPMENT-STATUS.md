# 开发任务与验证状态 · v0.2.0rc1

这是独立候选，不是正式主项目发布。当前入口：原文件 → prepare证据 → Agent一次补语义 → complete → 实际PDF复核 → review。

## 本轮已实现

- PDF原生文字/路径、Matplotlib类SVG轴刻度图例、PPTX分组世界坐标/原生连接绑定、位图几何候选提取。
- 精简Agent证据包与源/候选ID绑定；编译阶段生成原先需手写的裁切、刻度坐标和图例版位。
- 已核对朝内刻线的普通位图统计图、受控Matplotlib SVG统计图、原生文字驱动分组模板、通用节点/连接图。
- prepare/complete/status/review文件协议、Node薄桥接、未来独立入口semantic_provider回调。不内置模型SDK或密钥。
- 默认8pt一次内容布局，复用既有连续整图适配与6pt下限，不遍历输出8/7/6版本。
- 公共规则执行与适用性账本；真实复合字体、复杂单位/专业规则和印前验收仍列pending。
- 输入/证据/精简请求/源码哈希绑定，显式源范围，带标签刻度候选覆盖，原生已绑定箭头方向检查。
- 局部失败隔离、最多三次语义修复、未变成功项校验后复用；复用明示，不计新图首次提速。
- 对未处理输入、未解决异常、漏字、反向连接、被改写的单图/汇总/报告明确拦截。
- 字体只访问已配置路径，prepare不初始化字体；没有逐图扫描字体目录。
- 从输入读取到最终视觉review的墙钟埋点，保留Agent/工具等待，不把开发集成例当盲测。

测试及实际运行结果以本包外层“本轮验收报告”和验证日志为准，测试数量不是全刊规范验收证明。
