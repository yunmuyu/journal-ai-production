# 通用首次处理提速：开发目标与验收口径

## 当前事实
这次交付修复轴单位规范，没有声称实现新图全自动处理提速。v0.1.2的inspect.py对位图只返回尺寸/模式；PDF返回文字、字体和路径数量，但不直接生成可执行图件说明。统计图入口仍要求plot_clip、刻度position、图例安全区域等。因此瓶颈是源图到可执行结构的首次转换，以及编排往返和开发返工，不是约两秒的PDF后端。

上轮511.87秒混入基线读取、针对样本写适配及94项回归，不能当作成熟系统的每批生产速度。171.07秒完成基线核对，306.82秒完成适配与说明，360.40秒输出成功，511.87秒复核结束。这些是上一轮报告的累计检查点，不是逐函数性能剖析。

## 下一轮应落地的自动入图前端（以下是待实现，不是已有能力）

1. 一次读取生成证据包。PDF/SVG/Office优先取原生文字、对象身份、几何和关系；位图定位轴框、刻线候选、文字/图例候选区域。不识别数值数据点，不补画曲线。未知坐标变换、裁切或图源配对不明确时单独标疑点。
2. 模型一次填写语义，不逐图编写坐标脚本。模型读文字、确认对象角色、判定原图连接与保护区；程序把粗定位细化到实际线/文字对象，建立可追溯内部说明。框图输入节点与关系；统计图输入轴、标签和系列配对；混合图输入受保护素材版位。必要时仅针对局部不清楚区域复核。
3. 公共规则编译先于测字。已识别语义进入统一规则入口。每条规则记录来源版本、适用性、格式化函数、前检和实际PDF检查，以及完成/不适用/待核状态。不是在每个模板复制规则，也不靠每次模型回忆规范。
4. 有优先级的快速布局。默认8pt先求无冲突可行方案；原生图形保留，矢量几何不重建无须重建的部分。统计图外围采用确定性测量与边缘约束；框图调用节点/分组/连接布局。失败只处理对应约束连通区域，按当前完整图形缩放/6pt下限规则处理，不循环制作8/7/6三套PDF，不声称全局最优。
5. 一次生产调用完成处理和检查。独立图件解析/测量可有限并行，同篇版面协调后各图输出；按篇归拢。全套回归在代码或规则版本变化时运行，每图的内容、像素/路径、单位、字体、碰撞和实际PDF检查保留。已验证引擎不随每张图重新开发、重新遍历GitHub或重新扫描字体。
6. 异常定位而非整图重做。错误明确到对象、规则、测得净距及候选修复，不把原图内容不明当排版错误。局部重新测量仍需受影响区域和最终实际PDF检查。错误重试有上限，无证据不改内容。

## 验收方法
- 冻结引擎及规则后，使用未提前手写说明的保留测试图。旧三张只作回归，不用于宣传首次通用提速。
- 分开统计“已有支持图型的新样本”“首次出现的新图型研发”；不能混在一个平均秒数里。
- 收到可访问原文件即计时，到可交付PDF完成规定复核为止。包含图源提取、视觉模型调用、结构生成、格式化、布局、PDF、检查、工具往返和返工；用户等待确认时间单列。
- 记录批次墙钟、中位数、90分位、首次通过率、人工/模型介入次数、回退率；同时比较内容保护和版式合格率。
- 不以清空缓存后重跑旧说明代替首次新图测试，也不只报求解器或写PDF耗时。

## 本轮未完成
没有新增自动识图模型、自动轴框/图例识别器、通用图件说明生成器或完整自动生产编排，尚无盲测提速倍率。当前新增的是规则编译层中的明确轴单位格式化及其独立成品守卫。
