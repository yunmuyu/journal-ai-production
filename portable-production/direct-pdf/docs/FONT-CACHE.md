# 字体：一次配置，而不是每图扫描

配方角色：cn=宋体 Regular；punct=汉仪中宋简 regular；latin=Times New Roman Regular；latin_italic=Times New Roman Italic。CJK 标点集合及 `/ | - −` 等字符例外在配置中显式列出。该集合是候选规则，还需用本机复合字体样张核对，不声称与 Illustrator 隐藏分类逐字符完全一致。

正常启动只对配置的文件做存在性、文件大小和修改时间检查；cn 与 punct 指向同一字体时去重。未改变的字体不重新读取源文件计算 SHA-256，不重新解析名称表。它们的私有缓存和测字 SQLite 数据库按字体指纹隔离。一个批次、一个服务会话只加载每个独立字体一次。全量刷新必须显式 `fonts --refresh`；没必要每图刷新。

每次输出前只检查已绑定字体的轻量状态，防止批次过程中被替换，不遍历系统目录。统计中的 `configured_file_stats` 是初始化去重计数，不包含后续每图的轻量状态复核。

缓存位于 Windows `%LOCALAPPDATA%/JournalDirectPDF`；Linux 为 XDG cache 下的 JournalDirectPDF。可通过 `--cache` 更改。里面有字体字节及子集，**禁止上传、打包或分享**。源码包、本机示例包都不带该缓存。

局部斜体、上下标通过显式 runs 记录，不用 Unicode 字形“看起来像”代替；文字用 fontTools 的实际轮廓边界测量，与最终字体一致。中西文统一基线后按墨迹居中；多行逐行居中。当前不是完整 OpenType 排版引擎，不支持任意复杂连写/RTL；也未复现全部 Adobe 字距功能。字号整体 6—8 pt，局部上/下标字号应按刊物规则另验。

本机应至少核对：汉字、中文/英文标点、数字、拉丁字母、希腊字母、负号、括号、单位、正斜体、上下标、竖排文本、换行。缺字或缺样式直接阻断，不静默使用另一款字体。
