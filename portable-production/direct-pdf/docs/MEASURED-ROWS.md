# 等宽横排与编组对齐

`kind: "scene"` 的 `measured_groups` 横排可指定 `equal_width: true` 和
`target_width_pt`，让成员数不同的两排使用相同的整体宽度。宽度包括组内框间距；
例如两组都指定 `target_width_pt: 180` 和 `gap_pt: 3`，各框宽度根据成员数
分别计算，两组左右边界一致，组内框等宽、同行等高。

```json
{
  "id": "services",
  "axis": "row",
  "origin": [10, 20],
  "nodes": ["data", "map", "system"],
  "gap_pt": 3,
  "equal_width": true,
  "target_width_pt": 180
}
```

目标宽度仅用于显式等宽横排，必须为有限正数；文字真实墨迹和两侧规范留白放不下
时拒绝生成，调用者需要重新换行或调整版面。各框依然使用实际测字和框内留白审计，
不通过伪装为容器绕过检查。整图缩放时编组宽度与文字、框和间距同步缩放。

横排还可显式指定 `target_height_pt`，使成员采用相同目标高度。目标高度必须容纳组内所有文字及上下留白；不足时拒绝生成。高度进入几何复核并随整图缩放，不能用于跳过文字边界检查。

普通无连线框按需要显式设置 `gap_pt: 3`；该字段不改变原有默认值，避免破坏依赖
更大连接间距的旧图。分组位置、外框贴合和标题与框的净距仍需调用方明确设计与复核。
自动几何检查不能推断原图的图标、分支、线型、层次或用户希望的布局；必须与原图和
已通过同类样张逐项核对，不能将候选渲染成功当作用户终检通过。
