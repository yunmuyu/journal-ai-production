## 先处理仓库内部的差异

1. README仍有r18标题，但RELEASE.json与r21发布说明已经给出更新身份。不能仅凭README旧标题判断规范版本。
2. 菱形的文档基准为总宽1.7×文字宽+4pt、总高1.6×文字高+4pt；正式runtime在此基准上有字形包含修正。研发树采用另一种“矩形留白后乘二”的公式。本候选移植正式runtime的公式与包含修正，不把研发树全量覆盖到候选。
3. `tests/diamond-text-containment.test.mjs`要求带普通矩形4.5/2.7pt留白的矩形整体装进菱形；正式runtime的校准公式不是同一口径。本次记录该差异，未宣称跑过或通过该GitHub测试，也不为了通过它重新放大菱形。
4. 2026-10-13整图适配规则覆盖早期固定8/7/6档位顺序：先排内容，再完整等比适配已确认栏宽，允许6～8pt小数；低于6pt停止并要求重排，不能自动改双栏。
5. r21进一步覆盖“描边最终跟随缩放”的旧结果：实际最终可见路径描边归一为0.5pt。文字、框位置、箭头几何仍随整图缩放；最后单独执行描边规则。
6. .ai必交及Adobe专属验证被本次用户“PDF唯一必交、直接后端”要求替代；数据保护、字体、布局、实际PDF审核不因此删除。

## 部分支持、待接入与不能自动判定的规则

| 规则／问题 | 当前状态和边界 |
|---|---|
| 真正宋体／汉仪中宋简／Times New Roman、完整字符分类 | 仍需本机真实字体验收。当前样张明确用替代字体；不是正式复合字体通过记录 |
| 中文括号全角、范围全角～、轴单位量名/单位 | 普通字符串当前不自动猜语义改写；需显式角色/单位数据及专项测试。不能宣称全自动规范完成 |
| 变量斜体、数字下标正体、原生上下标等价 | 有显式样式片段，但真实字体、复杂公式及本机输出等价尚未完整验证；不凭模板推断变量 |
| 图例真实样符墨迹到文字3pt、逐行视觉中心 | 已统一槽位与文字，尚未对所有裁取样符消除内部白边并逐项实测；不能把槽位距离充当样符墨迹距离 |
| 位图真实刻线身份与全部像素保护语义 | 清字区外像素有检查，但保护区声明是否正确仍需原图对照。低清图刻线端点继续列待核，不补造 |
| 同篇同类内部绘图区宽高统一 | 这批两张同源SVG保持同尺寸；未建立跨任意作者全自动协调求解，不能用总画板尺寸充当绘图区 |
| 汇总线2mm还是3mm | 仓库同时记录脚本默认2mm与特定历史反馈3mm。本例树形用显式可配置bus_leg_mm、默认2mm；遇到已确认3mm案例以该案例为准，不全局覆盖 |
| 普通开始节点胶囊形、特殊形状/括号/专业符号 | 本批未出现标准“开始”节点。未宣称已实现全部形状和专业图种规范；真正椭圆不能全局改胶囊 |
| 电路单位规范、接线保护、地图比例尺等专项 | 本轮没有相应真实样本，未完成专项适配与验证 |
| Word完整图号、子图拆分与图例作用域 | 仍依赖明确制作说明及人工身份核对；本批源图号冲突不自行消解 |
| 低于6pt自动语义重排 | 现在明确阻断，而非自动改双栏；通用语义重排求解接入仍待完成 |
| 任意SVG/PDF描边归一 | 只支持并验证本批受控SVG变体。未知可见变换明确报错；一般PDF仅做实际线宽审计，不冒险改内容流 |
| InDesign置入、印厂PDF/X与本机正式接入 | 未完成；全部成果仍为候选，ready_for_publication=false |

## 验证不能越界

v0.1.0的49项测试没有覆盖完整规则迁移。本轮为86项本地回归测试，外加8张私有样图实际PDF检查与Poppler逐页复核；这既不是GitHub整个仓库测试通过，也不是Windows/Illustrator/印刷全链路通过。

当前只修改独立候选模块；不写GitHub、不改正式runtime、台账、已验收文件。已发现的研发／发布差异保留为差异项，不能按“后改的文件”静默合并。
