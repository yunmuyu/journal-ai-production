# 重绘关系与最终可见性门禁（开发版）

这两项接在公共 `render_one` 内，不用填写“已检查”布尔值代替证据。
已安装 r41 和已验收图件不会因开发代码改变。

## 独立来源关系合同

第一次核对原图后，将对象清单和关系保存为单独 JSON，绑定原始图源 SHA-256。
重排时只引用这份合同，禁止从待检候选重新生成合同来证明候选正确。
原图或已确认关系改变时，才重新核对合同；固定后由工具反复执行检查。

合同以 `role: "structure-contract"` 和文件 SHA-256 登记在 `sources` 中；作者原件以
`role: "original-artwork"` 登记。制作说明使用 `source_structure_contract: "relations.json"`。
存在合同登记时省略引用会报错；也可用 `policy.require_source_structure_contract: true` 强制要求。

```json
{
  "version": 1,
  "source_sha256": "<原始文件的SHA-256>",
  "nodes": {
    "a": {"shape": "rectangle", "visible": true},
    "b": {"shape": "rectangle", "visible": true}
  },
  "paths": {
    "ab": {
      "from": {"node": "a", "side": "right", "fraction": 0.5},
      "to": {"node": "b", "side": "left", "fraction": 0.5},
      "arrow": "end",
      "line": "solid"
    }
  }
}
```

工具检查最终编译 Scene 的完整节点和线清单，不能靠改成 decorative 绕过清单；检查节点形状、
框是否可见、箭头单/双向、实/虚线以及真实起终点。端口由最终节点几何重新求得，
不把候选自己的 endpoint_nodes 声明当作来源关系证明。普通 graph 和显式 scene 共用此检查。
可见性按白底上的非白描边或非白填充判断；纯白填充不能冒充一个可见框。
合同 paths 仅接受开放且不填充的线，不能保留同一 ID 后偷偷改成填充多边形。
端点匹配复用公共 0.15 pt 数值容差，不是新增排版间距规则。

无箭头的独立分隔线可将 from/to 都设为 null，基础检查覆盖数量、身份及实虚线。
若原图的两条分隔线必须上下分开，可额外声明
`"relations": [{"type": "path_order", "axis": "y", "paths": ["title-rule", "database-rule"]}]`。
该约束检查最终路径在指定轴上的完整投影按顺序分离，拦截合并、颠倒和跨层；`x` 轴同理。
它不固定排版间距，1e-4 pt 仅为坐标比较容差，报告会记录实测间隔。
没有此声明时不证明分隔线的位置；此约束也不适用于本来就应相交的路径。
版本 1 的连接端口支持节点四边；非矩形仅支持边中点。母线接点、图标端口、图片内部箭头等
尚不能以该合同自动证明，不支持时应报错或保留明确未覆盖状态，不能冒充普通节点关系。
合同不自动理解任意原图，也不证明节点文字或原稿身份本身正确。

## 最终 PDF 可见性

有独立原图素材引用或有效结构合同时自动启用。必须在保存 PDF、字体处理、裁边之后重新打开
实际文件，以同一页面坐标、300 dpi 比较；检查失败发生在原子替换候选文件之前。

旧任务也可设置 `policy.require_final_visibility: true`，独立检查全部素材、原生节点/线和黑字。
这只证明最终可见性，不能替代独立来源合同；`source_topology_checked` 仍明确记录是否核验原图关系。

作为连接符的来源箭头可用 `asset_boundary_contacts` 声明与节点的接触，例如
`[{"asset_id": "arrow", "node_id": "box"}]`。必须同时启用完整检查；仅接受矩形外缘、椭圆轴端的
外部描边接触（距离不超过节点半线宽加 0.001 pt 坐标容差），节点内部不得与素材矩形重叠。
检查将声明的节点边界实际绘入参考图，仍逐像素比较，而非豁免箭头端部。接触声明不证明原图语义。

- 素材：保护可见墨迹及围合的内部白色细节，检测新增遮盖和漏失；与外部相连的透明/纯白留边
  不视作图标实体。保护区由参考图自动计算，调用者不能提供任意忽略区域。未围合的白色开口
  和外部纸白无法自动区分，属于此项边界；加工前的独立原图比较仍使用完整区域。
- 合同内节点和线、原生黑色文字：检查实际墨迹是否被擦掉、盖白或裁掉。
- 线条和文字额外检查一像素轮廓邻域，防止黑块吞没对象却保留黑像素。线条两端 2 pt 邻域不做这项
  额外黑块判断，以容纳正常节点接驳；仍检查线和箭头的墨迹漏失。
- 原生线条轮廓检查参考其他开放线条及节点描边，避免把正常交叉当成黑块；填充块不进入该参考。
  文字轮廓不套用交叉线豁免，白底真正擦掉线条仍由墨迹漏失检查拦截。
- 纯白填充作为可能的遮挡物，通过被遮对象检查；不把白色空区本身当作黑色墨迹。
- 完全相同的同色重复覆盖无法仅从可见结果区分。白字的背景/对比度证明尚不支持，启用时明确报错。

比较沿用差值大于 8/255、变化比例超过 0.1% 的工程容差。节点/线/文字的分母是受保护墨迹，
不是整页面积；素材使用自动计算的保护区。容差不是任意精度、最小可检出面积或印刷兼容性保证。
报告记录对象 ID、覆盖范围和变化比例；报错还包含变化像素局部包围盒。

旧任务无来源合同/引用时报告 not-checked，不补写历史已通过，也不宣称完成这两项检查。

## 回归样例

全部为合成源文件，通过公共渲染入口或重新打开已保存 PDF 验证：
接错节点且同步伪造 endpoint_nodes、漏线、多线、反向、单双向变化、实虚线变化、形状变化、
缺合同、错误来源绑定、重复字段、白/黑块盖线、原图标遮挡、盖字、裁边截断、普通 graph、
小数坐标、整图缩放、独立分隔线合并/颠倒，以及实际 PDF 报告。作者原稿和已验收图不进入公开代码或测试集。
