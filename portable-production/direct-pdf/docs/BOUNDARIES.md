# v0.2.0rc1 当前边界

以下旧版边界保留为历史。现有对话/Agent入口和受控自动入图前端已实现；精简证据引用不需要用户量坐标。PPTX有原生对象提取，但没有完整PPT渲染器；需原PDF/截图核对图意。新位图入口仅在原图例去除经过安全确认后支持上方图外图例。普通语义图使用有预算的可行路由，不证明全局最优。

完整当前能力以CAPABILITIES.json和AGENT-ENTRY.md为准。任意格式无人值守、全刊字体验收、全部专业规则、主项目发布和新图通用提速倍率均未完成验证。

# 交付边界与候选范围

## 已实现并在容器中运行

- CLI：doctor / fonts / inspect / render / batch / serve / windows-fonts（Windows 注册表分支仅静态实现，未在 Windows 实机运行）。
- 可复用的 measured scene：矢量文字、矩形/圆角框/椭圆/菱形、折线路径、单/双箭头、虚线；七类模板/场景。
- 无数据重建的统计图：原生像素绘图区、Matplotlib SVG 路径及标记、保留原样符的图例、原位置刻度映射。
- 原始文件 SHA-256 绑定、源/输出路径隔离、字号/栏宽检查、文字与路径碰撞、形状文字包容、成品文字数量与字形、嵌入字体、实际 300 dpi 中性灰检测。
- 按类制作、按原图件清单归拢、一图一页汇总和静态/本地审核台。
- 在任何输出/失败报告写入前检查素材与输出目录隔离；Windows大小写图号冲突会阻断。批次、制作说明或字体配置改变时，审核台拒绝将旧PDF冒充当前结果。
- 服务端 allowlist 参数修改、新版本输出、不覆盖原始素材、候选备注持久化、会话恢复。改图后旧汇总被标为过期，不冒充新汇总。

## 未实现或未验证，不应宣布正式完成

- 从任意新图片/PPTX/Word 无需语义确认自动建立完整说明。当前由 AI/操作员准备说明，系统可靠执行。
- 本机正式复合字体等价性、Windows Cairo 依赖、本机 InDesign 置入、真实印厂 PDF/X。
- 主工作台正式接入/发布、现有 RELEASE 字节更新、正式台账迁移。本包没有执行这些写入。
- 完整的任意图布局求解。当前模板是确定性测字排版，`bridge/solve-existing.mjs` 是对已安装原求解器的显式调用桥，不宣称八张样图已经全部通过该外部求解器。原上传包还依赖主项目其他模块，不能孤立拷出一个 mjs 就运行。
- 任意 SVG 全保真：支持声明的 Matplotlib 分组，拒绝脚本、外部资源和不支持滤镜。转换后仍要实际看 PDF；源码路径哈希一致不自动证明所有渲染细节都一致。
- 位图图例随意移动。本版只在已经核对的原安全区域排；若放不下则失败。SVG 图例只允许已实现的图内位置并用已登记的路径避让；不是完整图像占用检测。
- 任意插图的普遍 PDF 文本换字。底层 PDF viewport 可用，但 source 文本与新文字不能未加区分地一起通过“已换字”检查。
- 色彩图、复杂公式/断轴/非线性坐标的自动语义处理、曲线被文字遮住后的恢复、低清曲线超分辨率补画。
- 完整几何拓扑证明。已有检查覆盖文字/路径/页面，不等于所有线交叉、节点关系及科学含义都自动证明正确。
- 拖曳自由编辑、可视化裁切编辑器、任意图例创建器；现界面提供有限参数和备注。

## 私有素材的疑点

完整试用包 evidence 中单独记录本批文字、图号及素材配对问题。源码净包不携带这些真实作者内容。来源不一致时保留显式警告，不自行润色、补画或默认为匹配。
