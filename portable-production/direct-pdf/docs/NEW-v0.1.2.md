# v0.1.2 新样本候选补充

基于用户上传的v0.1.1，仅增加带单位后缀的刻度、无边框图例、角部标签避让与灰度ICC修复。不是重做上一轮规则审计，也不是正式发布。

`policy.design_font_size_pt=8`为明确优先设计字号；不是同时导出8/7/6三版。统计图仍需已核对的素材说明，不保证任意截图全自动理解或全局理论最优。

新图例参数：`legend_frame: false`不画外框；`verify_legend_background: true`核对新图例加净距范围的原图墨迹；`legend_clearance_pt: 3`。带后缀刻度例如`{"text":"1.5G","number":"1.5","suffix":"G","position":465.5}`，原文必须等于数值和后缀拼接，不能暗改单位。

执行路径可在云端；旧文档关于本机字体/置入的记录是验收状态，不是渲染器对Windows或Adobe的依赖。预览配置不是生产复合字体。真实字体须由使用者依许可部署，源码包不含字体。
