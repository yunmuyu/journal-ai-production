# 期刊图件直接 PDF 引擎

> 本引擎随 r32 正式基线交付。安装与验收见 [发布指南](../../docs/RELEASE-GUIDE.md)，普通任务入口见 [制作入口](../README.md)。内部 `0.2.0rc1` 与下文旧“候选”标记保留为组件开发沿革；整体发布身份以根目录 `RELEASE.json` 为准，具体能力仍按 `docs/CAPABILITIES.json` 的各项开关判断。

对话/Agent 入口已接通。来源、视觉与语义复核仍需执行；引擎只生成候选，正式交付由 localflow 管理。

同排等宽框及不同数量的编组按统一总宽对齐，见 [等宽横排与编组对齐](docs/MEASURED-ROWS.md)。

开发版新增[原始区域独立核验](docs/ORIGINAL-ASSET-REFERENCE.md)：登记原始 PDF 后，自动比较准备素材，拒绝漏图层、异常裁切等差异；不等同于重绘连线语义已核验。

重绘后的连接另由[来源结构合同与最终可见性检查](docs/STRUCTURE-AND-VISIBILITY.md)验证，实际 PDF 保存后检查遮挡，失败不替换候选文件。

先读 **AGENT.md**，使用说明见 **docs/AGENT-ENTRY.md**。新增能力与边界机器可读表：**docs/CAPABILITIES.json**。

## 本轮新增

原始 PDF / Matplotlib 类 SVG / PPTX / 位图 → 原生对象或几何候选证据 → Agent一次确认语义 → 自动生成制作说明 → 既有规则与布局 → PDF和实际检查。

Agent通过候选ID引用原文、刻度和图例，不用再写精确裁切和逐图画图脚本。位图候选可能误报，不允许未经核对自动清掉数据。默认8pt先排，原有小数整图适配及6pt下限不变。

互不串联的多个流程可使用 `kind: "columns"` 和 `columns` 语义数组。每列独立使用通用 graph 布局；列 ID 作为对象命名空间，标题可选，列距与顶对齐由公共规则计算。`relations` 只记录跨列异步关系说明，不生成顺序流程边。

开发适配器 `model: grouped-chains` 支持两个上下容器、相反水平链及可选外部桥接节点；标题和节点均绑定来源，坐标由测量约束生成。仅合成测试覆盖，不能当作任意分组图支持或单栏适配保证，详见 [GROUPED-CHAINS.md](docs/GROUPED-CHAINS.md)。

原生PDF图件支持文字/路径提取和框图说明编译；**任意PDF统计图的自动清字/图例去除未接通**。标准Matplotlib对象和已确认朝内刻线位图统计图有可运行路径。

## 安装与验证

Python>=3.11。创建独立虚拟环境后 `python -m pip install -r requirements.txt`。已有环境可先运行 `python -m journal_pdf doctor --output doctor.json`，不要反复安装或扫描系统。

`python -m pytest -q` 运行软件回归（需要显式配置测试字体，源码不附带字体）。正常生产不逐图重跑整个测试集。

源码不含作者素材、字体、密钥、缓存。字体从已有配置读取，缺失不隐式替代。已知的 Linux 预览配置不是刊物生产字体。

## 本版主要变化

数值三位一空在测量之前处理；菱形移植正式runtime校准公式；普通框增加实际墨迹留白检查；流程直接箭头使用3mm基础、标签按实测避让；完整等比适配允许6～8pt小数，低于6pt阻断重排；最终路径0.5pt与文字纯黑检查；实际PDF裁边0.25pt；图外7pt身份汇总；引擎/规则改变使旧审核缓存失效。

本批SVG线宽按新规则规范化，但路径和dash属性保留，位图曲线没有重画。任意SVG变换或PDF内容流的线宽改写不在本版自动支持范围。

## 边界

当前替代字体样张不等于宋体/汉仪中宋简/Times New Roman验收。复杂图种、公式、上下标语义、全部图例墨迹净距、单位规范、Word归属、InDesign及PDF/X仍有待验证项。永不自动标记正式放行。

代码与样图仅存独立候选目录；本机试用包含真实作者素材，不能整体上传GitHub。源码净包不包含素材和字体，适合人工审查后放入候选分支。
## 矩形框边非中心接点

`scene` 中默认字符串端点绑定框边中心；要在矩形框边的其他位置接线，请将 `endpoint_nodes` 对应端改为 `{"node":"框ID","side":"bottom","fraction":0.8}`。`side` 可为 `top`、`bottom`、`left`、`right`；`fraction` 是沿该边从左到右或从上到下的比例，范围 0 到 1。实际路径端点必须与声明位置一致，两端可使用不同的比例来实现上下错位框的直连。引擎仍检查真实边界、碰撞和箭头末段长度；非矩形或不能证明的接点不能借此冒充矩形。审计报告的 `node_boundary_ports` 留存通过检查的接点。

对于已确认需要同距的向下直连，可在 `scene` 中声明 `"straight_vertical_spacing":[{"paths":["箭头1","箭头2"]}]`。默认按普通直连的最终尺寸 3 mm（约 8.5 pt）核对，并记录实测值；路径必须是单段向下的直箭头。合流等需要更大间距时显式给出 `gap_pt`，例如某图确认的 15 pt 为该图的具体方案。历史规格若确需 23 pt，必须显式指定。检查不改变阶段箭头间距，也不自动移动节点或代替人工确认。

stage-grid 节点可以声明 `fill_column: true`，将节点拉到本列实测宽度，供同列等宽与紧凑连接使用；这不会改变未声明节点。连线标签按实际文字墨迹和线条外缘留出 3 pt（8 pt 基准），而非用固定字符基线偏移代替净距。仍需保证分叉、文字、原图连线语义和中心接点的空间。

对于能明确绑定两端矩形框的单段水平或竖直箭头，工具还会自动记录直连距离；超过 3 mm 基准的项目提示复核，避免手写坐标绕过检查。连接线跨越多行、汇合、避让或其他布局需要时可以更长，提示不等于错误；未绑定、折线、斜线和非矩形目标不属于自动检查范围，仍需核实。

若两框可以通过各自框边中心直连，应优先保持中心到中心的直接连线；不要为压缩另一条箭头的距离而将该直连移到非中心接点。关联箭头无法同时满足默认距离时，保留实现对齐所需的间距并复核，不改变图的连接关系。

对于上排为并列框、下排为一个总框的版式，优先让下排框的左右边与上排框组的外侧边对齐；还须检查文字留白和容器边距。此项目前需要显式排版及视觉复核，尚未自动求解。

## 原图裁切、数值标注和单位核对

对源 SVG 图组，`source_svg_group` 默认仍要求所选图元完整位于选区。若原图的长柱形等图元本身由 SVG 矩形裁切隐藏，且选区完整包含该原生裁切范围，可以显式设置 `clipped_viewport: true`；只有工具能证明裁切范围、坐标及内容流未变时才接受。变换、样式或裁区无法证明时仍报错，不以成功导入代替人工核对。

对于散点或折线图，可在 scene 规格中逐条声明 `data_label_bindings`，包含 `text_id`、`asset_id`、`source_label_id` 和从零开始的 `marker_index`。工具只对所声明的标注检查原文、原 SVG 图组与点的颜色和坐标、目标文本位置；同色同位置无法区分时拒绝。它不能证明未声明的标注或整个图表都正确，仍须核查原图及重合点。

标签需要移开时，可增加 `leader_path_id`，要求引线起点靠近标签、终点对准该声明的原数据点；画出的箭头及实际阅读效果仍需人工查看。`source_plot_frame` 可绑定原 SVG 的四条简单直线轴与目标矩形框，拒绝框线与原轴边界不一致或非等比缩放；复杂轴、变换及不完整来源不属于此验证范围。

图例和曲线的区别不能靠人为更改虚线来制造。对源 SVG 系列，`source_legend_bindings` 将图例线及标记绑定到实际系列，核对线宽、灰度、虚线节奏及标记；手工 scene 数据曲线则可用 `legend_series_checks` 对比图例线和对应曲线的线型、灰度和线宽。`legend_dash_checks` 以 12 pt（8 pt 基准）作为起排建议；短于此值提示人工核对，不以周期数或 12 pt 作为不可调整的硬限制。无效线型或样线完全被遮住仍报错；工具不能保证短样线可辨，须看实际成稿。

横轴题与刻度的距离可用 `axis_label_gap_checks` 显式检查：默认以刻度文字墨迹的最下边到轴题墨迹的最上边 3 pt 为基准，允许有明确证据的图单独配置。此检查只针对指定文字，不自动排版或认定所有轴题适合这个距离。

同一检查支持 `side: "left"` 和 `side: "right"`，分别用于左侧纵轴题和右侧色条题。`axis_tick_gap_checks` 对每个明示的刻度文字和刻度线计算文字墨迹到线条外缘的距离，默认 2.5 pt（8 pt 排版基准）；整图缩放时同比换算。工具绘制的平头刻度线以路径端点为外缘，不额外加半个线宽。对密集刻度、特殊字体或不适合该数值的图应单独决定，并保留真实数据位置。

刻度线保留在源 PDF 图元中时，`source_tick_gap_checks` 可指定源资产和刻度文字，渲染实际 PDF 后查找唯一对应的竖直源刻度、核对实际路径并测量 2.5 pt 间距；测量根据 PDF 中实际平头、圆头或方头计算线端。当前只支持可唯一辨认的横轴竖直刻度，无法确认时阻断并要求人工核对，不推断图中其他线条。图表模板自动核查有轴题的文字间距；对于没有经过验证的原图刻度，会标记需要复核，而不会宣称刻度间距已通过。必要的拐角避让也会单独提示。

新绘的水平或竖直刻度默认长度为 2.5 pt（8 pt 排版基准），可用 `new_tick_length_checks: [{"path_id": "刻度线ID"}]` 绑定独立直线检查；确需调整时声明 `length_pt` 和原因。原图中保留的刻度按源图，不因这项规则被改写。未声明的刻度不在此项检查覆盖范围。

普通标签多行默认按相邻可见文字墨迹净距 3 pt（8 pt 基准）测量和排版，明确传入 `leading` 时保留调用者指定的基线间距；有空行时保留空行。历史规格若把节点或箭头坐标写死，行距变化会使坐标失效，必须重排并重新审计，不能只重绘文字。分支线旁的“是／否”文字可用 `confirmed_spacing_checks` 中的 `connector_label` 绑定路径、文字及文字相对路径的 `side`，默认墨迹到线条描边净距 3 pt，例外按实际布局说明原因。

互不相连的平行线，以及不连接的线与矩形框，描边外缘默认至少留 3 pt（8 pt 基准）。`route_clearance_checks` 需明确指定 `kind`（`line_line` 或 `line_frame`）、两个对象编号和从零开始的直线段编号；对象多于最低净距无需拉近。确需更小间距时填写 `min_pt` 与原因，仍不得相碰。工具目前只核验相互平行且投影相交的水平或竖直线段、矩形框；箭头末段、共同母线、已连接框和不支持的几何不会被误称通过，须另外核对。未显式绑定的线条和原图中的线条不在检查范围内。

数据标签到对应点的 3 pt 仅是宽松起排参考，不作为统一硬门槛；优先保持源数据、避免遮挡并确保标签归属。绑定的源点只能证明点中心时，不冒称已量得标记外缘；标签因密集避让离源点较远时可填写 `placement_reason`，工具保留源身份核验并要求人工复核归属，不自动要求引线。

`annotation_clearance_checks` 可显式绑定图表中的数值文字与另一文字（`labels`，参考 2.5 pt）、外侧图例矩形框（`legend_frame`，参考 3 pt）、绘图区矩形框（`plot_frame`，参考 1 pt）。默认以 8 pt 为基准；间距不足仅提示人工复核，真正的文字重叠或文字与对应框相交仍不得当作通过。允许以 `target_pt` 和 `reason` 记录特殊排版。检查采用保守的文字墨迹包围框；倾斜字、网格、原生素材和未绑定的数据关系必须在实际 PDF 中另外核对，不能仅以包围框近距认定重叠或宣称整图已审。

相邻刻度文字可用 `annotation_clearance_checks` 的 `ticks` 绑定，参考净距 2 pt（8 pt 基准），按逐字墨迹外接多边形计算保守距离；图表模板自动按原始坐标顺序检查相邻刻度，绝不为拉开间距移动数据位置。允许 0.15 pt（随字号缩放）的测量容差，密集时以看清与不重叠为先。测得过近只提示复核，不能仅凭整段文字的包围框重叠断言真实字形相撞。

`icon_ink_checks` 显式绑定原图矢量图标和文字（`icon_text`，图标在左或在上时参考 3 pt），或图标与矩形框（`icon_frame`，左右至少 4.5 pt、上下至少 2.7 pt）。对可确认的源矢量图标，以实际 PDF 的隔离渲染结果测量可见墨迹（0.05 pt 像素），而非素材裁片边缘；裁片碰到墨迹边界、图片或无法验证的素材进入人工复核。stage-grid 自动绑定图标检查，图标在左或在上均缺省按墨迹安排文字；既有明确 `icon.gap` 仍按指定值执行并复核。余量可保留，无法排下或有遮挡时可调整并说明原因。以上参考均按 8 pt 字号设计，随字号等比缩放。

`icon_group_centers` 显式绑定图标、文字和矩形框，在指定 `axis`（`vertical` 或 `horizontal`）上按组合墨迹边界检查整体居中；stage-grid 自动绑定并尽量以实际墨迹居中。图标不能可靠解析时必须复核最终 PDF，不能把裁片中心视为真实墨迹中心。另需核对与连线及其他图元的关系。

横纵轴交界处的刻度文字同样参考刻度文字之间 2 pt（8 pt 基准），不另设一个用户规范。图表模板检查两轴标签之间的距离；必要时调整标签而不移动原始刻度和数据。内部排版的角落避让初值与此一致，明确例外仍需视觉核对。

`curve_label_checks` 显式绑定数据文字与原生路径（`path_id`）或可验证的单条源 SVG 曲线组（`asset_id`），以 1 pt 为参考。检查以文字墨迹包围框和整条描边包络保守估计，不把浅灰网格当作曲线，不移动数据点或原曲线。裁剪、曲线归属或几何无法确认时提示复核；虚线空白和文字真实字形不能由包围框证明碰撞。遇密集情况可用 `target_pt` 与 `reason` 记录灵活调整。

数据标签确需引线时，`data_label_bindings` 记录引线起点到文字包围框的描边净距，1 pt（8 pt 基准）为参考；太近或明显偏远时提示人工复核，密集或遮挡时可以调整。引线末端仍须指向绑定的原数据点，不能用这项参考替代对应关系和最终视觉检查。

新绘的原生点或方块与水平图例样线可通过 `legend_marker_centers` 绑定：默认把标记中心移到样线中点，线型、标记大小和灰度不变；如须保留原图特殊位置，显式设置 `apply: false` 和原因并人工复核。此能力仅支持无关联文字或连接的原生圆形/矩形标记；源图片、PDF 或 SVG 整体图例样例不会拆开或擅自改动，若含标记仍需人工核对。样线长度可以变化，不固定标记两侧的数值。

`legend_frame_gap_checks` 可显式核对图例框底边与最下行图例文字的间距，也可用 `side: "right"` 核对框线内侧到最右文字墨迹的净距。声明 `legend_backgrounds` 时，两侧会自动核对文字和前景图形的实际边界：8 pt 基准各为 4.5 pt，整图缩放时同比变化。源素材样例裁切区域不等于可证明的符号墨迹，须独立复核。

树形图 8 pt 基准的框线外缘净距：同组 2.5 pt、组间 5 pt，字号及整图缩放时同比变化。并排图片的默认净距为 4 pt（8 pt 基准），scene 可用 `image_row_gap_checks: [{"asset_ids": ["left", "right"]}]` 声明同一行的素材，由工具按其有序边界检查；尚未自动编排图片或识别未声明的图片行。
图片上方和下方说明的默认墨迹净距为 6 pt（8 pt 基准），`image_label_gap_checks` 逐项指定 `asset_id` 及 `title_id`、`caption_id`；缺少声明或图片内部文字不在检查范围。

`confirmed_spacing_checks` 按明确绑定对象检查新确认的 8 pt 基准净距：图例样线或符号到文字 3 pt（`legend_key_text`）、拼图上下相邻图像 4 pt（`image_grid_vertical`）、多行说明文字 3 pt（`caption_lines`）、容器左右到内部框 4.5 pt（`container_horizontal`）、容器标题到子框 3 pt（`title_to_frame`）、同组无连线框 2.5 pt（`sibling_frames`）、虚线容器上下到内部框 3 pt（`container_vertical`）。对象须确有相应类型和可验证位置；规则不会识别未绑定项目。遮挡、箭头或版宽要求变更时可明确提供 `gap_pt` 和非空 `reason`，报告保留例外。图例样本为原图位图时，裁切框不一定是墨迹边缘，须人工核对。

工具也会根据矩形包含关系，尝试识别容器的直接内部框并检查上下净距；该推断仅生成复核提醒，不把几何包含当作已证实的语义归属。容器有自身标题时，顶部文字与内框使用标题规则，不误当成空白。对经核实的特殊版式，可用 `container_spacing_exceptions` 同时记录容器 ID、直接子框 ID、上下方向、实测值和原因；对象或实测值变化后例外不再生效。只有显式绑定的 `confirmed_spacing_checks` 才是确定对象的严格检查。

统计图模板按各行文字墨迹和样例占位测算图例行位置，使用已确认的 3 pt 文字行净距及 2.7 pt 上下留白（8 pt 基准）；若源样例裁片包含不可识别的空白或原图固定区域限制高度，仍须核对实际 PDF，不能声称其样例墨迹边界已验证。

第五组新增：容器内标题墨迹到上框内缘 3 pt（`container_title`）；行名文字到右侧图片 6 pt（`image_row_label`，同列行名右对齐）；独立阶段箭头到上、下框分别 1 pt（`stage_arrow_before`、`stage_arrow_after`）。阶段箭头的检查只支持明确绑定、墨迹可计算的矢量路径；源图片或 PDF 裁片边界不能冒充图形墨迹，须实测。普通直连沿用箭头端点到端点 3 mm（约 8.50 pt）的默认值；0.5 pt 框线的外缘净距约 8.00 pt。无箭头的合流首段优先 6 pt，箭头末段仍须满足最小长度；绕线、标签、箭头长度或空间限制可用其他数值并记录原因。

明确绑定图例框和数据折线时，工具检查是否碰线，同时将小于 1 pt（8 pt 基准）的实测净距列为复核提示；图例避让数据优先，提示不等于碰撞，也不代表未绑定的曲线或图像已经核查。图例可以移动、缩短样线或调整间距；有条件时保留原始数据。

`legend_backgrounds` 为声明的真实矩形图例框绘制完全不透明的白底，再绘制明确列出的图例前景路径、文字和节点。数据路径仍保存在 PDF 中但在白底范围内被遮住；未显式分组的外部图例资产暂不支持。工具检查前景是否落在白底范围内，仍应在实际 PDF 检查白底和文字可见性。
已声明的 scene 图例按框线内侧与文字、符号的真实边界检查上下各 2.7 pt；可确认的单列文字相邻墨迹净距为 3 pt。统计图专用生成器也按文字墨迹和图例样例的实际边界计算行位置与上下留白；较高的样例可能需要增大行距，固定尺寸或无法测量墨迹的源图例仍须复核。基准为 8 pt，整图缩放时同比变化。多列图例须人工复核。

`parallel_slant_checks` 可显式指定同组直斜箭头的 `path_ids`，比较它们相对于竖直方向的倾斜角；最大角度差超过 0.5° 时提示复核。该数值是检查容差，不是规定所有斜箭头的统一角度；路径必须是已登记的两点斜箭头，未绑定路径和原图中的线条不在检查范围内。工具只提示，不自动改变连线或原图关系。
白底与源数据是否重叠仍须编辑复核；scene 中名为 `legend-frame` 的图例如未声明遮底和前景，也会标记待复核，而不把未检查当成通过。其他命名、位图内图例和无法识别的源数据不在这项自动识别范围内。

图例靠近绘图区边框时，3 pt 为默认净距，不得因此遮盖或紧贴数据：先检查可绑定的数据曲线，必要时缩短图例样线并收窄图例框；虚线仍须保留至少两个完整周期且与曲线线型一致。若仍有碰撞，可调整图例位置或外侧净距并记录例外。`legend_data_checks` 可绑定图例框与明确的数据折线路径，检查描边相交；无法识别或未绑定的数据、位图和 SVG 资产不能据此声称已排除遮挡。本项目前只检查、不自动决定移动或缩短方案。

轴题支持由已识别单位组成的乘除表达式，例如 `速度(m/s)` 转为 `速度/（m/s）`；未知单位、公式或含义不确定的括号留待检查。普通文本中的常见多字符单位（如 `15kHz`、`10mm`）与数字之间会加空格；代码、路径及易混淆的单字符单位不做推断。规则不会转换单位或更改数值。
