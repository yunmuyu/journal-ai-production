# 2026.10.28-spacing-clip-candidate

This candidate normalizes spaces between confirmed frequency quantities and
Hz, kHz, MHz or GHz, while retaining source values, unit case and protected
literal boundaries. The actual-PDF audit checks the space independently.

Column widths are upper bounds: a narrower figure no longer triggers a width
warning, while an over-wide page still fails. Partial EMF inspection records
OffsetClipRgn as a mapped logical vector and preserves its SaveDC/RestoreDC
behavior. Unknown clipping and mapping remain explicitly unknown. Emitted
geometry is not clipped and device-region rounding is not fully modeled.

Windows full direct-PDF tests: 984 passed and 7 subtests passed; 3 failed while
creating symbolic links with WinError 1314, as in the previous baseline. The
full suite ran before the final small extraction of clip helpers; after that
refactor, 57 affected tests passed. Figure-audit guard selftest passed 19/19.
The no-excuse Python checker reported no violations in 18 figure-audit files;
basedpyright and ruff were not run. Synthetic anisotropic and 90-degree rotated
clip-offset tests were compared with actual Windows GDI results.

This is a release candidate, not a runtime deployment, formal print release,
full EMF renderer, InDesign placement validation or PDF/X certification.
