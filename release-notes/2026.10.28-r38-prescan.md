# 2026.10.28-r38-prescan (release candidate)

Adds an evidence-only single-page PDF prescan. It does not determine layout suitability or approval. Results require human inspection.

Validation so far: 38 focused prescan and figure-audit contract tests passed on Windows. This candidate is not a deployed or published release.

PDF scene text now registers its font subsets before importing PDF forms, preventing reuse of a conflicting source subset. The PDF guard documents the explicit bitmap count limit; it does not verify image fidelity.
