# r42：原图关系与最终 PDF 可见性检查

新增独立原图区域比较、绑定原件哈希的结构合同，以及保存后 PDF 可见性检查。检查失败发生在替换候选文件之前。

- 原图区域比较核对准备素材与原件，阻止裁掉细节、丢失内部白色形状和新增图形。
- 结构合同核对节点与连线清单、形状、方向、实虚线、实际接点及声明的分隔线相对顺序；不使用候选自报关系充当原图证明。
- `policy.require_final_visibility: true` 可独立检查旧任务。素材保护可见墨迹和围合白色细节，排除外部纸白；支持经过几何核验的图元接框声明，避免正常接框和交叉线误报。
- 保存后遮图标、箭头、文字的实图反例均被拦截；失败时保留原候选。

## 验证

本机全量 1291 通过、3 失败、0 跳过，另有 7 个子测试通过；专项 58 通过。3 项失败均在创建符号链接夹具时触发 WinError 1314，未更改系统设置或放宽测试。既有锁定可选 Shapely 依赖在隔离目录安装，EMF 裁剪 17 项已纳入全量验证。

一张私有实图从既有来源规格重新生成：122 个对象通过可见性检查，300 dpi 与已通过稿像素一致；三种破坏性修改均被拦截。私有稿件、商业字体、本机配置与测试输出不在公开包中。

## 范围与升级

最终可见性通过不等于自动理解原图；没有独立来源合同仍明确报告原图关系未检查。外部相通白色开口、同色同形覆盖、白字和印前兼容性存在文档所列边界。详见 [接口与边界](../portable-production/direct-pdf/docs/STRUCTURE-AND-VISIBILITY.md)。

便携 ZIP 与 SHA-256 随 Release 提供；按 [升级指南](../docs/RELEASE-GUIDE.md) 隔离安装和验证。本次发布不自动切换已安装 r41，也不修改已验收图件。
