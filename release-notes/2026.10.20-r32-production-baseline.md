# 2026.10.20-r32-production-baseline

十月生产公共能力的正式交付基线。保留现有工作台与 Adobe 兼容路线，当前制作入口为 portable-production。本版不改图形布局算法，不重制已通过图件，不覆盖本机运行目录。

## 变化

- 根目录改为正式产品入口，补齐安装、外置配置、升级、回滚和更新日志。
- RELEASE.json 同时锁定 production-runtime 与 portable-production；旧安装器字段保持兼容。
- 提供可复现便携 ZIP、逐文件 BUNDLE-MANIFEST.json 与下载 SHA256；拒绝未跟踪文件、机器配置、字体和生产稿件入包。
- 修正源码 direct-pdf 与安装目录 engine 的入口差异，两套并存时阻断。
- 纳入此前 PDF 字体兼容门禁与未使用字体资源误报修复（PR #7、#8）。

## 本次实际验证

Windows，Python 3.12.14，Node 24.18.0，复用本机已有依赖和包外正式字体。

- Node 离线检查：51 通过，0 失败。
- localflow：14 通过、2 个子测试通过，含完整 probe/render/review/publish/accept 状态链与字体缺陷回归。测试中的人工意见为隔离的协议夹具，不是生产稿的终审证据。
- 发布包构建：3 项测试通过，覆盖可复现字节、解压后篡改检测、密封源变化拒绝、私有/未跟踪输入拒绝。
- 源码目录与旧安装目录兼容、缺失和双引擎阻断均已测试。

解压包最终验收记录随 Release 单独提供，包含包哈希、入口、依赖和样本结果；历史 r31 完整测试统计不作为本次重新执行的结果。

## 交付与边界

便携 ZIP 是当前制作路线；完整工作台、Adobe 与历史协作工具位于同 tag 的 Source code 包。作者文件、字体、机器配置、状态、缓存和截图不公开分发。组件内部版本号及历史记录保留，整体版本由本 Release 与 RELEASE.json 确定。

本轮不重新认证所有图种、全新机器、Adobe/PS 自动链路、InDesign 实际置入或印刷 RIP。PDF 解析、渲染及软件门禁不能替代这些检查。Windows Cairo 动态库与生产字体须由接手机器合法配置并验证。保留此前验证边界；未覆盖项明确转人工。

后续变更以短期分支和小补丁发布，带对应回归、更新日志和新校验和，不覆盖已发布的同名资产。
