# PDF render audit candidate

This candidate is based on the r32 source baseline plus the isolated PDF decoding
gate. It does not include r33/r34 layout candidates and is not a formal release.

The former compatibility gate could accept readable PDF page trees with corrupt
content/font streams. The new shared renderer checks every page and blocks decoder
diagnostics. Typesetting preview can call its CLI without copying implementation.

Fresh validation: 18 localflow tests and 2 subtests; synthetic corrupt content/font
negative cases; a native two-page synthetic export through the consuming preview
adapter; separate Poppler rendering and inspection. Full figure-engine regression,
fresh-machine installation, manuscript acceptance and print validation were not
performed for this candidate.

The first CI attempt failed on the stale r32 portable-file hash. This candidate
identity and manifest correct the package/source mismatch without changing tags,
existing release assets, frozen historical manifests or installed runtime. The
original corrupt-export cause and font-metric warnings remain unresolved.
