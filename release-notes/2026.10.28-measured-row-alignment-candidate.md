# 2026.10.28 measured-row alignment candidate

Measured scene rows can specify a shared overall width for equal-width cells,
including the requested inter-cell gaps. The compiler refuses a target that
cannot accommodate measured text and required padding. Scene audit continues
to validate each cell, and proportional artwork scaling scales the width
contract with the actual geometry. The feature does not infer source topology
or automatically compact enclosing frames.

Focused checks: 40 passed, including a real generated PDF with different cell
counts and matching row boundaries. The full direct-PDF run before the final
end-to-end test addition reported 1,039 passed, seven subtests passed, three
failures caused by Windows symbolic-link privilege and one skipped test because
Shapely was unavailable. All three failures also occur in the unchanged
baseline. These environment-limited cases have not been validated here.

This is a release candidate, not a deployed runtime. Source/visual review,
Adobe/InDesign placement and print output remain outside these checks.
