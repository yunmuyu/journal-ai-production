## 改动

- 原路线可选独立合同锁定端点、折点、遍历方向、共用干线与箭头，只允许声明的全图变换；复用最终 PDF 可见性检查。
- 现有 PDF 回传门增加有范围说明的交付检查单；离线候选、工作台待终检、用户验收分开记录。
- 混合 PDF 按真实 Do/Form 图片实例识别，保护相同 RGB 下不同透明蒙版、尺寸、裁剪、放置矩阵和矢量/图像绘制顺序。
- 非零/负裁区原点通过公共准备模块归一化，检查路径、原生文字、图像与实际像素保真；不修改原件。
- `journal capacity` 提前给出当前布局的容量、字号与几何证据，不自动换栏、不覆盖用户决定；有原路线合同的图同时检查该合同。
- `journal package` 为显式可选动作，仅从当前交付清单收集指定稿件/图号，验证哈希、保留待终检/定稿状态，不自动触发。
- 2 pt 留白增加测量像素保护，避免旧四舍五入容差允许实际低于2 pt；不缩放原内容。

## 验收边界

- 私有真实图件只在工作区副本/只读路径验证，没有纳入 Git 或公开包。
- 图片内部及转曲文字覆盖仍须独立证据，原有覆盖门不放宽。任意混合 PDF 并不因此都可自动出版。
- 容量结论是当前方案实测，不是所有可能布局的全局最小宽度证明。
- Linux 不具备 Windows ICU 中文分词组件，完整引擎中的6项现有相关测试在未改r47与本补丁上同样失败；Windows GDI、Adobe/InDesign和未配置的特殊字库测试仍有平台条件。
- 启用真实字体的完整 Node 集成测试还有4项原有夹具失败（两项文字覆盖登记、一项候选状态、一项缺少图件身份）；在未改r47上重复得到相同失败，未为通过测试放宽生产门禁。
- 未修改生产配置、冻结签名、已验收文件、工作台状态或远端 Git。上线前需要在目标Windows/Adobe环境复验并单独批准安装。
