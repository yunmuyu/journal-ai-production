# r44：裁边与交付证据门禁

PDF 导出默认按可见墨迹四边留白 2 pt；可明确指定其他值。保存后检查实际留白并对照原视口，不能原位修改来源；不缩放图形或字号。旋转页、空白页和核验失败会阻断。旧图批处理同样使用该检查。

正式 PDF 交付要求完整场景可见性、重绘来源结构及素材区域证据；未解决警告须逐条绑定具体候选和核对记录。预览仍可生成，用户终审仍独立进行。图表支持绑定 PNG/JPG 原图区域；原图语义、白字对比度等不在机械证明范围。

Windows 本机整合专项 86 项、交付与预检 275 项通过；5 项符号链接测试因本机权限未运行。引擎全量和 GitHub CI 结果见版本验证记录。原稿、字体及私人样例不包含在公开包中。
