# 工具整合版 r30

版本：`2026.10.18-r30-final-tools`。整合此前未推送的 r22/r29 公共工具修复，保留 portable-production 普通入口及 Adobe 原生兼容路线。正式 runtime 与 Skill 字节由 RELEASE.json 锁定，研发树与 runtime 的既有差异继续保留。

本轮修订：

- 补充文字与非 owner 矩形框边的碰撞检查。
- 接通 outside-top 的界面选项和执行入口。
- layout_build_count 记录实际布局构建次数。
- doctor 明确报告缺失依赖，便于判断当前机器可执行的范围。
- 原生文字检查逐字符覆盖普通小字；原生上下标按其专门规则处理，不将其正常缩小字号误判为普通文字违规。
- 水平 via 连接按实测标签宽度保留轨道，避免后续路由覆盖已计算的文字间距；无标签的原有轨道不变。
- 无效的空文字替换项返回明确校验错误，不再在组合附标检查中提前崩溃。

此前 r22/r29 的标签摆放、单栏整图复用、最终 PDF 图片色彩和物理虚线审计、组合附标保护等修复一并保留。测试数量与实际结果见 [本版验证记录](../release-validation-20261018-r30.json)，不把历史记录计作本轮新跑。

本轮 Adobe 适配器仅局部修订有标签的水平 via 轨道；原生合成回归及其他测试结果以本版验证记录为准。此前实测另见 [r29 验证记录](../release-validation-20261018-r29.json)，不计作本轮新跑。本机缺少 PyMuPDF/fontTools/pytest，完整 portable 端到端渲染未验证。PDF 物理字号矩阵解析尚未实现；矩形以外曲框边界不在本轮检查范围。缺失私有样本的集成测试显式跳过，原断言保留。复杂拓扑、文字归属和变量语义仍需结合原图与实际 PDF 核对，机械通过不替代用户终检。

后续制作优先复用已有可编辑 PPT 或原图，保持绘图区比例；复杂拓扑先核对来源和连接，不盲目重绘。对同图修订一次汇总后执行，保留原件及已验收成品；作者素材、字体和本机配置继续留在仓库外。
