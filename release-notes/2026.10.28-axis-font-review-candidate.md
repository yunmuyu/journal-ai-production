# 2026.10.28-axis-font-review-candidate

Review notices identify a base font below 8 pt, reduced ordinary rich-text
runs, and inconsistent decimal places on explicitly grouped numeric axes.
Charts use their declared x/y ticks; primitive scenes may declare
`axis_tick_groups`. Missing groups are explicitly flagged. The tool does not
automatically alter numeric precision or decide whether a shifted run is a
legitimate mathematical script. Editorial notices leave the PDF available for
review but set `overall_checks_passed=false`.

Focused Windows tests covering typography, axis formatting, scientific text,
quantity spacing and crop behavior: 175 passed. A real local figure's original
mixed-precision y-axis was flagged and its revised axis no longer raised that
notice. Private figure data is not included in the public repository. The two
new Python modules passed the no-excuse checker; basedpyright and ruff were not
run. The prior full direct-PDF baseline had 1,029 passes, 7 subtest passes and
3 Windows symbolic-link privilege failures; full suite was not rerun here.

This is a release candidate; no production runtime deployment, Adobe placement
validation or print certification is claimed. Output format must be specified
per figure and verified by the delivery contract, not inferred from capability.
