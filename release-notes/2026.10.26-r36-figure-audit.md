# 2026.10.26-r36-figure-audit

本版从 r35 主线整合已验证的公共修复，作为新的源码及便携包版本；没有自动部署或修改已安装运行环境。此前 GitHub Release 下载页仍为 r32，r33—r35 已合入的能力随本版统一交付。

## 纳入范围

- 首次加工入口要求记录来源结构、文字处理需求及数据保护证据，阻断“需要换字却仅转灰度”的不一致路线。建议不是自动识图结果或终审。
- 原生 PDF/SVG 完整文字登记、保留非文字图形、独立文字来源绑定；不再通过很小的可见 PDF 画面承载纯文字来源证明。无法证明来源或覆盖范围时仍阻断或要求人工核对。
- 存储数量单位空格：例如 `52.4KB` → `52.4 KB`，保留数值、大小写及富文本样式；保护代码、路径等字面量。审核实际 PDF 中空格，不再仅靠忽略空白的文字计数。
- 按字符、位置、字号、方向匹配实际 PDF 的字体，避免“文档某处有斜体”掩盖目标变量仍为正体。只核对已声明样式，不自动判断变量语义。
- 树组间距使用普通净距的倍数、保留图分支方向和跨层关系；支持实际文字旋转测量；修复嵌套 SVG marker 定义规范化引起的几何签名误报。
- 区分 PDF 结构告警与解码告警，仍保持原有发布阻断，不能因能够栅格化就宣称字体或结构无问题。

## 未纳入与遗留问题

密集数值标注的自动避让、箭头 callout、白底遮罩、自动统计图间距及图例实验、尚缺充分负例和实际 PDF 验证的新增 graph 分组框没有进入本版。相关真实样图仍为未通过且已暂停；最新 callout 测试仍有实际 PDF 审核失败。试验分支和私有证据保留，不随正式包启用。

本版不表示九篇样稿全部完成，也不表示任一整期期刊终稿完成。已通过样图维持原冻结版本，未因发布重做。真实稿件、字体、生产台账、失败样图和私人路径未随公共发布包提供。

## 使用和迁移

下载本 Release 的便携 ZIP 和 SHA256，解压到新目录，按 [安装、升级与回滚](../docs/RELEASE-GUIDE.md) 校验文件。复用包外合法字体和依赖、建立独立状态/输出副本后再试运行。完整旧工作台和 Adobe 兼容工具使用同一 tag 的 Source code。

旧审核记录如果缺少 `source_review` 或 `text_review` 会被新门禁阻断；应回看真实来源补证据，不批量填写“无文字”放行。新版 PDF 审核也可能阻断旧版未识别的字体样式问题。支持边界见 `portable-production/direct-pdf/docs/SOURCE-TEXT-COVERAGE.md`。

软件回归、实际 PDF 渲染、视觉/语义审核、Adobe 原生验证和用户终审互相独立。本轮不操作 Adobe/InDesign，未做目标排版置入、印刷 RIP 或无人值守生产验收。
