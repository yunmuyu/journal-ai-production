# 原生换字：导出前排布

PPT 提供完整文字、样式与所属模块依据；中转格式只负责保存图形。不要从 PDF 碎片重猜原文字，也不要根据最近的矩形猜标注对象。已验收图不因工具升级重做。

## 制作顺序

1. 核对正文中的变量和下标，再确定字号、换行及允许的文字方向。
2. 从当前同源图形的 inspect 结果明确绑定 `ownerPathIndex`，记录对应的 PPT 对象或模块依据。索引跟随本计划的 `sourceHash`，源改变后重新核对。
3. 框内或面上的模块标签在 `texts[]` 中声明 `layout`。数字矩阵等已明确定位的其他文字也会作为固定文字障碍。
4. 固定公共 render 入口在同一份 Illustrator 文档中创建、测量完整原生文字，计算容纳与近距离避让；既定字号和上下标保持不变。允许的 90°方向仅交换已测墨迹宽高，选定后复用同一个文字对象。
5. 无解时返回 `labelPlacement.issues`，不保存 AI/PDF。先按该报告调整布局计划，不能先导出再凭视觉反复试摆。算法不会自行缩字号、改连线或猜拆图。
6. 成功时重测实际落位；位置差超过 0.05 pt 阻止导出。用原生几何和实际墨迹直接定边界，一次保存，不再打开文件做像素裁边。最后仍核对一次实际 PDF，主要检查导出异常和内容。

```json
{
  "text": "Conv3×3",
  "x": 0.5,
  "y": 0.5,
  "align": "center",
  "valign": "center",
  "anchor": "ink",
  "layout": {
    "ownerPathIndex": 7,
    "placements": ["inside", "left", "right", "above", "below"],
    "clearancePt": 1.5,
    "maxDistancePt": 8,
    "rotations": [0, -90],
    "allowFrameExpansionPt": 0
  }
}
```

`clearancePt` 为本标签的边界净距；此示例不是普通流程框留白标准的替代。按图种规范明确设置留白。默认先框内居中，再选择所属对象附近的合法候选；不是寻找整张画布里任意远处的空位。`maxDistancePt` 限制外部文字与所属图形边界的距离。

图形的面内部可放字，边界和可见线段是障碍。其他文字、箭头轮廓和图片的裁切后可见范围也需避让。只有明确的原生绘制顺序及不透明填充完整遮住候选区域时，才忽略其后方被遮住的线；缺少证据时保守处理。曲线沿用分段近似，不宣称对任意专业图都已覆盖。

虚线轴对齐矩形只有显式设置 `allowFrameExpansionPt` 才能小幅外扩，上限 6 pt；不得越出画板、扫过邻图/文字或改动其他路径。报告保存修改前后的控制点。其他路径仍逐点核验；有扩框时 `pathGeometryPreserved` 为 false，`protectedGeometryPreserved` 表示仅允许的框改变，不能笼统声称全图完全未变。

## 混合矢量与图片

PDF 灰度处理保留矢量、文字、图片资源调用、变换及裁切，只替换内嵌图片的像素和颜色空间。常见不透明 8 bit RGB/Gray、RGB ICCBased、Flate/JPEG 已覆盖；同图重复引用只转换一次。`imageConversions` 记录尺寸、转换与像素哈希。

软蒙版、颜色键蒙版、显式 Decode、非 8 bit、CMYK等未验证输入仍给出明确错误，不静默铺白或整图栅格化。不要为了绕过混合图限制反复手工重建数字矩阵。
